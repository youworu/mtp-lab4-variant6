## Простые числа и замер времени

```bash
python main.py primes --limit 10
```

Результат — `[2, 3, 5, 7]`. Граница включается, если она простая; для 0 и 1
получается пустой список. Отрицательная граница вызывает ошибку.

В `prime_numbers()` используется `yield`. Делители проверяются до целого
квадратного корня числа включительно. Без аргумента генератор не имеет верхней
границы; получать его значения нужно частями, например через `islice`:

```python
from itertools import islice
from numbers_tasks import prime_numbers

print(list(islice(prime_numbers(), 5)))  # [2, 3, 5, 7, 11]
```

Декоратор `time_execution` измеряет длительность вызова через `perf_counter`,
сохраняет имя и описание функции через `wraps`, возвращает исходный результат.
Если функция выбрасывает исключение, время также записывается, а исключение
передаётся вызывающему коду.

Декорирована функция `collect_primes`, которая собирает значения генератора
в список. Поэтому измеряется получение чисел до границы, а не только создание
объекта генератора. Декоратор предназначен для обычных синхронных функций.

## Чётные числа

```bash
python main.py evens -4 -3 0 1 2 3 4
```

Результат — `[-4, 0, 2, 4]`. Функция использует `filter` с лямбдой, сохраняет
порядок и повторы, не меняет исходный список. Пустой ввод даёт `[]`.

## Фильтрация файла через генератор

Пример входных данных: [examples/events.txt](examples/events.txt).

```bash
python main.py filter-file examples/events.txt ERROR
python main.py filter-file examples/events.txt ERROR --ignore-case
```

Первая команда выводит две строки с `ERROR`; вторая — три, включая строку
с `error` в нижнем регистре. Поддерживается поиск по кириллице.

`filter_file_lines()` открывает UTF-8 файл при начале перебора и читает его
построчно. Строки выдаются через `yield` без перевода строки, остальные пробелы
сохраняются. Весь файл в список не загружается. При полном переборе файл
закрывается автоматически; если перебор прекращён раньше, генератор можно
закрыть методом `close()`.

Отсутствующий файл, неверная кодировка и пустая строка поиска дают сообщение
об ошибке. Если совпадений нет, команда ничего не выводит и завершается успешно.

## Собственный reduce

```bash
python main.py reduce 1 2 3 4
python main.py reduce 1 2 3 4 --operation product
python main.py reduce 1 2 --initial 10
python main.py reduce --initial 0
```

Результаты по порядку: `10`, `24`, `13`, `0`.

`custom_reduce(function, iterable, initial)` сворачивает значения слева направо.
Начальное значение необязательно: если его нет, берётся первый элемент.
Для пустого iterable без начального значения выбрасывается `TypeError`.
Явно переданный `None` отличается от отсутствующего аргумента.

Функция работает с любым итерируемым объектом, включая генератор, и не собирает
его в список. В реализации не вызывается `functools.reduce`: стандартная
функция импортируется только в тестах для сравнения результатов.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Проходят 50 тестов: 13 для числовых функций, 5 для декоратора, 11 для
фильтрации файла, 13 для собственного `reduce` и 8 для командной строки.
Проверяются ошибки ввода, сохранение метаданных и исключений функции,
построчное чтение, закрытие файла, порядок свёртки и запуск программы
отдельным процессом. Проверки времени используют подставные показания часов,
поэтому не зависят от скорости компьютера.

Проверка стиля в Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m flake8 .
```

В Linux путь к интерпретатору окружения — `.venv/bin/python`.
При ошибках аргументов программа сообщает причину в stderr и возвращает код 2.
