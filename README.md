## План работы

Логика заданий размещается в отдельных модулях, ввод и вывод — в `main.py`.
Для каждого задания добавляются тесты обычных случаев и ошибок. Фильтрация
файла выполняется построчно; собственный `reduce` принимает также генераторы.
Зависимости нужны только для проверки стиля через flake8.
